# Telegram-бот заказов APITEKS

Бот для заказа продукции с сайта [apiteks.uz](https://apiteks.uz). Товары, пользователи и заявки хранятся в **Appwrite**, который работает на вашем сервере (self-hosted, бесплатно) и доступен по IP-адресу сервера. Товары добавляются и редактируются прямо в консоли Appwrite.

## Логика для пользователя

1. `/start` → приветствие и кнопка **«🛍 Товары»** (а также «📦 Мои заявки» и «☎️ Контакты»).
2. **«🛍 Товары»** → карусель всех товаров: фото, название, цена за единицу, минимальный заказ. Листается кнопками ◀️ ▶️, а кнопка «📋 Список всех товаров» открывает список для быстрого перехода.
3. **«ℹ️ Подробнее»** → полное описание, характеристики, список марок, все фото.
4. **«🛒 Заказать»** → выбор марки (если есть, можно пропустить) → количество (не меньше минимального) → телефон (спрашивается один раз, потом запоминается) → проверка заявки → **«✅ Отправить заявку»**.
5. Клиент видит: «✅ Заявка №N отправлена! Наш менеджер обязательно свяжется с вами в ближайшее время… ожидайте 🙂».
6. Администраторам (`ADMIN_IDS`, `ORDERS_CHAT_ID`) приходит заявка с товаром, количеством, суммой, телефоном и ссылкой на клиента, а также кнопки «В работе», «Выполнена», «Отменена». Клиенту приходит уведомление о смене статуса. Команды админа: `/orders`, `/orders_new`, `/reload`.

## Как добавлять и менять товары в Appwrite

Консоль: `http://IP_СЕРВЕРА` → ваш проект → **Databases → apiteks → Товары (`products`)**. У каждой колонки в консоли есть подсказка.

| Колонка | Что это |
|---|---|
| `name` | название (обязательно) |
| `description` | описание |
| `price` | цена за единицу в сумах; пусто — в боте «по запросу» |
| `unit` | единица: м, м², кг, шт, рулон… |
| `min_order` | минимальное количество для заказа |
| `active` | `false` — товар скрыт в боте |
| `sort` | порядок в списке (меньше — выше) |
| `image_ids` | ID картинок из Storage, первая — главная |
| `specs` | характеристики |

- **Изменить цену, описание и т.п.:** откройте строку, поправьте и сохраните. В боте изменения появятся в течение минуты (`CATALOG_TTL_SECONDS`), или сразу после `/reload`.
- **Новый товар:** нажмите **Create row** в таблице «Товары» и заполните поля.
- **Картинка:** **Storage → Картинки товаров → Create file**, загрузите фото, скопируйте его **File ID** и добавьте в `image_ids` товара.
- **Марки товара:** таблица «Марки товаров» (`variants`), в `product_id` укажите ID товара (колонка `$id` в таблице «Товары»).

После первого импорта у всех товаров цена пустая («по запросу»), минимальный заказ равен 1, а единица подобрана по названию. Цены и минимальные количества нужно один раз заполнить вручную: на сайте их нет.

## Структура

```
bot/                  код бота (aiogram 3)
  schema.py           структура таблиц Appwrite
  db.py               работа с Appwrite (TablesDB, Storage)
  catalog.py          кэш товаров (перечитывается из Appwrite раз в минуту)
  handlers/           обработчики: товары, оформление заявки, заявки и админка
scripts/
  scrape.py           парсер apiteks.uz -> data/catalog.json + data/images/
  setup_appwrite.py   создаёт базу, таблицы, индексы, бакет
  import_catalog.py   загружает каталог и картинки в Appwrite
data/                 спарсенный каталог и скачанные картинки
deploy/install-appwrite.sh   установка Appwrite на Linux-сервер
Dockerfile            образ бота для запуска на сервере
tests/offline_flow.py офлайн-проверка сценария бота (без Telegram и Appwrite)
```

## 1. Appwrite на сервере

Нужен Linux-сервер (Ubuntu 22.04/24.04 или Debian) минимум с 2 CPU, 4 ГБ RAM и открытыми портами 80 и 443.

```bash
scp deploy/install-appwrite.sh root@IP_СЕРВЕРА:/root/
ssh root@IP_СЕРВЕРА
sudo bash install-appwrite.sh IP_СЕРВЕРА
```

Скрипт при необходимости поставит Docker и установит Appwrite 2.7.4 в `/opt/appwrite` без интерактивных вопросов: домен — IP сервера, порты 80/443, секреты генерируются автоматически. После этого:

1. **Сразу** откройте `http://IP_СЕРВЕРА` и зарегистрируйтесь. Первый пользователь становится владельцем, дальнейшие регистрации в консоли закрыты.
2. Создайте проект и скопируйте его ID.
3. В проекте откройте **Overview → Integrations → API keys → Create API key** и отметьте все права разделов **Database** и **Storage**.
4. Заполните `.env` (`copy .env.example .env`):
   ```
   APPWRITE_ENDPOINT=https://IP_СЕРВЕРА/v1
   APPWRITE_SELF_SIGNED=true
   APPWRITE_PROJECT_ID=...
   APPWRITE_API_KEY=...
   ```
   Для IP-адреса настоящий SSL-сертификат не выдаётся, поэтому Appwrite отдаёт самоподписанный, и `APPWRITE_SELF_SIGNED=true` разрешает его принимать. Трафик при этом шифруется. Если позже привяжете домен, укажите `https://домен/v1` и `APPWRITE_SELF_SIGNED=false`.

## 2. Telegram-бот

1. Создайте бота у [@BotFather](https://t.me/BotFather) и впишите токен в `BOT_TOKEN`.
2. Впишите свой Telegram ID в `ADMIN_IDS` (узнать ID можно у [@userinfobot](https://t.me/userinfobot)).

### Вариант А: бот на том же сервере (Docker)

Скопируйте папку проекта на сервер вместе с `.env` и выполните в ней:

```bash
docker build -t apiteks-bot .
docker run --rm --env-file .env apiteks-bot python -m scripts.setup_appwrite   # таблицы, индексы, бакет
docker run --rm --env-file .env apiteks-bot python -m scripts.import_catalog   # каталог + 233 картинки
docker run -d --name apiteks-bot --restart unless-stopped --env-file .env apiteks-bot
docker logs -f apiteks-bot
```

### Вариант Б: бот на любом компьютере (Python 3.11+)

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python -m scripts.setup_appwrite
.\.venv\Scripts\python -m scripts.import_catalog
.\.venv\Scripts\python -m bot
```

## Обновление каталога

Каталог уже спарсен в `data/`. Чтобы подтянуть новые товары с сайта, выполните `python -m scripts.scrape`, затем `python -m scripts.import_catalog`. Импорт только **добавляет** новые товары и марки: ваши цены и правки в Appwrite не затираются, а ничего не удаляется. С флагом `--overwrite` обновятся тексты и картинки с сайта у существующих товаров, но цены, единицы, минимальный заказ, `active` и `sort` всё равно не трогаются.

## Таблицы Appwrite (база `apiteks`)

| Таблица | Назначение |
|---|---|
| `products` | товары: цена, единица, минимальный заказ, описание, картинки |
| `variants` | марки товаров |
| `users` | пользователи бота и их телефоны |
| `orders` | заявки (номер = `$sequence`, статус, количество, сумма, контакты) |

Картинки лежат в бакете `product_images`. Права на таблицы не выдаются: доступ к данным есть только у бота по API-ключу.
